# Last Light

A casual lantern game for Android and the web. Baddies want your flame. In the light they can
only steal it; in the dark they can hurt you. Toss your lantern to light them up, zap them to
win your flame back, and relight every tower in the lighthouse.

## What's in the game

- **15 levels** in 3 worlds (The Cellar, The Library, The Lamp Room), with 1–3 stars per level.
- **A short story**: Pip the lamplighter against the Gloom King, who is the final boss.
- **9 kinds of baddies**: Nibbler, Sneak, Peekaboo, Snatcher, Skitter, Blob, Huff, Grabby and the Gloom King.
- **Shop**: 9 permanent upgrades bought with coins.
- **Endless mode** (unlocks after level 5), a daily gift, and heart and sunshine pickups.

## Controls

| | Phone | Computer |
| --- | --- | --- |
| Move | Drag anywhere | WASD or arrow keys |
| Toss the lantern | Quick flick, or tap a spot | Click, or Space |
| Pause | Pause button or Back | Esc |

## Project layout

| Path | What it is |
| --- | --- |
| `src/ll.js` | The game: rules, levels, shop, story, rendering, UI |
| `src/art*.js` | All sprites, drawn in code (no image files) |
| `src/audio.js` | Sound effects and music, synthesised in code (no audio files) |
| `src/fx.js` | Particles, screen shake, floating text |
| `src/shell.html` | Page markup and styles |
| `src/build.py` | Bundles everything into `www/index.html` |
| `www/` | The built game plus fonts. This is what the app serves |
| `android/` | The Capacitor Android project |
| `store-icon-512.png` | 512 px icon for the Play Store listing |

Everything in the game is original or openly licensed: the art and audio are generated by the
code in `src/`, and the fonts in `www/fonts/` (Fredoka, VT323, Press Start 2P) are under the
SIL Open Font License.

## Build and run

Requires Node 20+, Python 3, JDK 21 and the Android SDK (API 35).

```bash
npm install
npm run sync        # rebuilds www/index.html and copies it into the Android project
npm run open        # opens the project in Android Studio
```

Or from the command line:

```bash
cd android
./gradlew assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
./gradlew bundleRelease     # needs your signing config
```

To try it in a browser, open `www/index.html` through any local web server.

## Before publishing

- The app ID is `com.afkdevelopers.lastlight` (in `capacitor.config.json` and
  `android/app/build.gradle`). Change it there if you want a different one.
- Add your release signing config in `android/app/build.gradle`.
- Version is `1.0` / code `1` in `android/app/build.gradle`.
- The game stores progress only on the device (WebView local storage). It collects no data and
  needs no permissions beyond what Capacitor adds by default.
